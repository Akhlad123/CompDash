# CompDash — Microinverter Telemetry Comparison Dashboard

A free, open-source, client-side React dashboard for comparing microinverter telemetry
across multiple solar sites. No backend required — all computation runs in the browser
via DuckDB-WASM. Deployed to GitHub Pages.

---

## Prerequisites

- Node.js >= 18
- npm >= 9
- Git

---

## Local Setup

```bash
git clone https://github.com/<your-org>/CompDash.git
cd CompDash
npm install
npm run dev
